문제

진열대에 보석이 한 줄로 놓여 있다. 모든 종류의 보석을 하나 이상 포함하는 가장 짧은 연속 구간을 [시작 번호, 끝 번호]로 돌려준다. 번호는 1부터 센다.

가장 짧은 구간이 여럿이면 시작 번호가 가장 작은 것을 고른다. 정확성과 효율성을 따로 채점한다.

제한

  • 보석 1~100,000개

입출력 예

gemsresult
["DIA","RUBY","RUBY","DIA","DIA","EMERALD","SAPPHIRE","DIA"][3, 7]
["AA","AB","AC","AA","AC"][1, 3]
["XYZ","XYZ","XYZ"][1, 1]
["ZZZ","YYY","NNNN","YYY","BBB"][1, 5]

원문은 프로그래머스에서 연다.

힌트 사다리

    • 투 포인터와 슬라이딩 윈도: 창의 오른쪽 끝을 늘리고, 줄일 수 있으면 왼쪽 끝을 줄인다.
    • 딕셔너리와 집합: 창 안의 보석 종류별 개수.
  2. 진열대 [A, B, A, C, B]. 오른쪽 끝을 늘리다 4번(C)에서 세 종류가 다 들어온다. 왼쪽의 A(1번)는 창 안에 A가 또 있으니 뺀다 → 창 2~4 (길이 3). 5번을 넣으면 2번 B를 뺄 수 있다 → 창 3~5 (길이 3). 가장 짧은 길이는 3이고, 그중 시작이 빠른 [2, 4]가 답이다.
  3. 창 안의 종류 수가 전체 종류 수와 같으면, 지금 창이 "이 오른쪽 끝에서 끝나는 가장 짧은 구간"이다. 지금까지의 최단보다 짧을 때만 바꾼다. 같으면 바꾸지 않으니 먼저 찾은(시작이 빠른) 구간이 남는다.
  4. 1. 전체 종류 수 K를 센다. 2. 빈 딕셔너리, left = 0, 최단 답 = 무한대. 3. right를 끝까지: 개수 +1 → 맨 왼쪽이 2개 이상인 동안 빼고 left += 1 → 종류 수가 K이고 더 짧으면 [left+1, right+1]. 4. 답을 돌려준다.
  5. 시안에서는 열지 않는다. 앱에서는 풀이 문서 5~7단계(코드, 실행 추적, 복잡도와 흔한 실수)를 보여 준다.
두 번째 힌트부터는 이 시도가 오답으로 기록돼요.
1def solution(gems):
2 kinds = len(set(gems))
3 count = {}
4 left = 0
5 best = [1, len(gems)]
6 for right, g in enumerate(gems):
7 count[g] = count.get(g, 0) + 1
8 while count[gems[left]] > 1:
9 count[gems[left]] -= 1
10 left += 1
11 if len(count) == kinds and right - left <= best[1] - best[0]:
12 best = [left + 1, right + 1]
13 return best
